# GENtle TSS Collection Skill

`gentle-tss-collection` is a descriptor-only OpenClaw/ClawBio surface for the
six shared-shell actions taught by tutorial 08.15. It delegates every command
to the registered `gentle-cloning` runtime. Preview, list, validation, and GUI
handoff are read-only; materialization and registry removal use the runtime's
content-addressed proposal/approval contract.

The skill contains no independent coordinate calculation, TSS classifier,
sequence derivation, collection store, command runner, or biological
interpretation.
