# Transcript-assay informative fallback fixture

## Origin

`irf9_acceptance_reference.json` is a hand-crafted metadata fixture created for
GENtle's approval-bound transcript-panel fallback tests. The executable locus is
built deterministically by
`src/engine/tests.rs::irf9_informative_fallback_acceptance_engine`; it uses
synthetic DNA and an `N`-only mature-cDNA class labelled with the public IRF9
transcript accession `ENST00000699070`.

The JSON also cites hashes and counts supplied with the motivating IRF9 replay.
Those values are external reproduction evidence, not files regenerated by this
fixture. No source sequence, project state, laboratory result, or private
analysis artifact from that replay is included.

## Deterministic recreation

1. Build the two assayable synthetic transcript classes from the literal DNA
   strings in `irf9_informative_fallback_acceptance_engine`.
2. Add one 180-base `N`-only mature-cDNA feature with transcript ID
   `ENST00000699070`.
3. Run the strict `one_per_class` operation with `coverage_policy=require_all`.
4. Run the approval-bound wrapper with an informative fallback budget of two
   assays.

The Rust test constructs this state in memory; no network or external tool is
required.

## GENtle usage

`src/engine/tests.rs` uses this fixture to verify that the strict failure keeps
the uncovered transcript in a typed record and that preapproval produces a
separate, digest-linked, explicitly partial panel within budget. The metadata
file prevents the synthetic acceptance test from being mistaken for a replay
of the cited study state.
