# RNA-read batch gene-support screenshots

These native GENtle captures were recorded on 2026-10-01 from a disposable
state built from the retained Ensembl-116 TP53 locus and twelve committed cDNA
read fragments split across two gzipped FASTA samples.

The fixtures are deliberately small acceptance inputs, not a sequencing-depth
benchmark. Both reports contain six aligned reads and no seed-passed reads; all
six alignments are target-assigned fragments, with no complete molecule or
direct exon-transition support. The captures therefore document the important
distinction between alignment assignment, phase-1 seed filtering, molecule
completeness, and junction evidence.
