# Public manual GUI Shell checkpoint

This directory retains one untouched X11-root capture and its complete semantic
snapshot from a manual/hybrid walkthrough of the public synthetic plus/minus
TSS fixture. It is tutorial evidence, not an automated GUI acceptance result.

The run used no private input and did not invoke the inner agent. The GUI Shell
called the same `features tss-tfbs-profiles` route documented in tutorial 08.13,
with the exact `MA0004.1` panel and `shared_across_tss` scaling. The output
receipt records two windows, both strands, preserved ambiguous-window nulls and
the exact producer binary.

[`evidence.json`](evidence.json) binds the candidate, executable, inputs,
output receipt, raw capture and semantic snapshot by SHA-256. The screenshot is
not cropped or annotated. Failed exploratory captures remain in the original
candidate evidence directory for diagnosis and are not presented as tutorial
success images.
