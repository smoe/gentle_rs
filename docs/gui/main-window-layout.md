## Main window layout

<!-- manual-counterparts:start -->
Related CLI reference: [Window and Display Intents](../cli/display.md).
These topic links do not imply identical feature coverage across interfaces.
<!-- manual-counterparts:end -->

The main project window holds the project overview, lineage, containers and
arrangements. Opening a sequence gives it a separate DNA window with its own
map, bases and annotation controls. Use the Windows menu to return to an open
view; opening a tool does not create a separate project.
